# ASR 轉譯報告

> 產生日期：2026-10-03
> 資料鏈：`ryza_main/top500/` → `tools/pos_label.py` → `tools/asr_screening.json` → `data/ryza_train.list`
> 流程說明見 [`docs/04_transcript_pipeline.md`](../docs/04_transcript_pipeline.md)；評估標準見 [`docs/01_overview.md`](../docs/01_overview.md) §4。

> **CER 的定義（§3）**
> - **reference（ground truth）**：隨機抽出的 50 段，經人工逐段聽音檔校對後的文字（[`cer_sample.csv`](cer_sample.csv)）
> - **hypothesis**：同 50 段的 **Whisper 原始輸出**（專有名詞校正之前）
> - 抽樣：`random` seed 42，自 491 段抽 50 段
>
> 也就是說，CER 衡量的是 Whisper 本身的轉寫錯誤率，不是校正後清單的錯誤率。

## 1. 模型與參數

| 項目 | 設定 |
|---|---|
| ASR 模型 | faster-whisper **large-v3**（CTranslate2 後端） |
| 推論裝置 / 精度 | CUDA（RTX 4070S 12G）/ **float16** |
| **beam size** | **5** |
| **temperature** | **梯度 fallback（0.0 → 1.0，faster-whisper 預設）** |
| VAD | 開啟（Silero VAD，經 onnxruntime） |
| 語言 | `ja`（固定，不偵測） |
| 時長門檻 | 2.0s ~ 15.0s（免模型，讀 WAV header） |
| initial_prompt | 無 |
| 音訊來源 | `wav/`（48kHz / 16bit / mono） |

> **temperature 未固定的選擇理由**：實測固定 `temperature=0.0` 時，`wav/04493.wav` 會陷入 `……` 無限重複幻覺（compression_ratio 20.34，被 HIGH_COMPRESSION 規則捕捉）。改回預設梯度 fallback 後該段恢復為正常文字「せめて、何かきっかけでも作れれば…ん?」。代價是重跑結果可能有少數段差異，故採預設梯度。
> **ASR 模型**使用 faster-whisper（CTranslate2 後端）載入 Whisper large-v3 權重。faster-whisper 為 Whisper large-v3 的推理框架實作，模型權重相同，差異在於推論速度與顯存佔用（原環境 RTX 3060 6G 顯存不足，遷移至 RTX 4070S 12G 後採用 faster-whisper 以提升吞吐）。若需以 openai-whisper 重現，載入同一份 large-v3 權重即可。

## 2. 處理量與過濾統計

### 資料漏斗

```
500  top500（依 svm_dec 排序）
 -3  WRONG（人工確認非ライザ）          → neg_labels.py WRONG[]
 ────
497  ASR 輸入（pos_label.py SVM_DEC[]）
 -6  DUPLICATE_TEXT（跨檔文本重複）      → neg_labels.py DUPLICATE[]
 ────
491  有效段數（data/ryza_train.list）
```

> **WRONG[] 的兩個口徑**：`neg_labels.py` 的 `WRONG[]` 是**全庫**人工確認非ライザ的累計清單，共 **23 筆**。
> 其中只有 **3 筆**落在 top500 範圍內，漏斗扣除的就是這 3 筆；其餘 20 筆在 top500 之外，不參與本報告的計算。

### 必要過濾規則觸發統計

必要的過濾條件為：時長 <2s 或 >15s、非說話聲、ASR 輸出為空、重複或明顯幻覺（[`01_overview.md`](../docs/01_overview.md) §4）。對應實作如下：

| 規則 | 門檻 | 觸發數 | 對應條件 |
|---|---|---|---|
| DURATION_SHORT | < 2.0s | 0 | 時長 <2s |
| DURATION_LONG | > 15.0s | 0 | 時長 >15s |
| EMPTY | VAD 後無文字 | 0 | ASR 輸出為空 |
| HALLUCINATION | 命中已知幻覺句 | 0 | 明顯幻覺（Whisper 常見幻覺輸出） |
| REPETITION | 同字元連續 ≥4 | 0 | **重複**（指 ASR 輸出的重複幻覺） |
| NON_SPEECH | core 為感嘆詞 | 0（REVIEW） | 非說話聲（喘氣、吶喊等短促感嘆） |

**必要過濾規則全數未觸發**（0 排除），497 段音訊在這些條件下品質乾淨。

### 附加過濾

以下規則是基於 TTS 訓練需求另外加入的，與必要規則中的「重複」是不同概念：

| 規則 | 門檻 | 觸發數 | 說明 |
|---|---|---|---|
| HIGH_COMPRESSION | compression_ratio > 3.0 | 0（REVIEW） | Whisper 幻覺指標；實測最高僅 1.54。「明顯幻覺」的必要規則是 HALLUCINATION，此規則為另一種補充指標 |
| **DUPLICATE_TEXT** | **core 跨檔 ≥2** | **6（EXCLUDE）** | **跨檔同一台詞重複錄製** |

> **DUPLICATE_TEXT ≠ 必要規則的「重複」**：後者指單一檔案內 ASR 輸出的重複幻覺（上表 REPETITION，觸發 0）；DUPLICATE_TEXT 指的是**不同音檔收錄了同一句台詞**（遊戲多個 cue 引用同一段語音）。
>
> 排除 6 段的理由：這 10 個音檔 MD5 互不相同、時長些微相差，是同一句台詞的重複錄製，**對 TTS 訓練保留一個版本即可**。

## 3. 品質抽查：50 段人工校對 CER

### 抽查方法

- 自 491 段以 Python `random`（**seed=42**）隨機抽 **50 段**（佔 10.2%，seed 固定可重現）
- 每段提供 Whisper 轉換後的逐字稿，由**人工逐段檢視音檔比對**
- reference 與 Whisper 原始輸出相同 = 該段經檢視後**判定無誤**（44 段）
- reference 與 Whisper 原始輸出不同 = 該段 Whisper 輸出**有誤**，reference 為人工填入的正確文字（6 段）
- **CER = Levenshtein(reference, hypothesis) / len(reference)**，hypothesis 為 **Whisper 原始輸出**
- 比對前兩邊都過 core 正規化（去標點、只保留日文/英數字元），避免標點差異干擾

### 結果

| 指標 | 數值 |
|---|---|
| **平均 CER** | **1.0%** |
| 字元錯誤總數 | 10 / 1114 字元 |
| 完全正確（CER = 0） | 44 / 50 段（88%） |
| 有錯誤 | 6 / 50 段（12%） |

- **同音異字**：オート→王都（おうと）、諸子→書庫（しょこ）

## 4. 專有名詞校正

- `CORRECTIONS` 收錄 **6 條已確認誤聽**，每條皆有 CER 人工校對或
  全庫掃描依據（對應上表 6 段錯誤中的 5 段；id40 的語頭語氣詞
  「な」不屬專有名詞，未收入 glossary）
- 另補上全庫掃描確認的 `ボース→ボオス`（6 檔全數誤聽，未落在 50 段
  抽樣內但經逐一檢視確認）
- 推測型誤聽（`リザ→ライザ` 等）本庫 0 次觸發，**不收**；
  `ヴォルカ→ヴォルカー` 因會把正確的 `ヴォルカー` 改成 `ヴォルカーー`
  （子字串誤改），**不收**

  與 `screen_asr.py` 採同一字元過濾規則

**校正結果**：14 筆逐字稿修正、`data/ryza_train.list` 重產為 491 行

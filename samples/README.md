# 生成樣本（repo 展示用）

本目錄是 **16 epoch 正式訓練**產生的參考音訊副本，供 reviewer 直接聆聽評估。
音檔原始位置：`<GPT>\logs\ryza_v4_lora\infer_e16\`；本目錄為**複製件**，
20/20 檔案的 SHA256 與來源完全一致。

## 產生條件

| 項目 | 值 |
|---|---|
| S1（GPT／AR）權重 | `GPT_weights_v4/ryza_v4_lora-e16.ckpt` |
| S2（SoVITS LoRA）權重 | `SoVITS_weights_v4/ryza_v4_lora_e16_s1904_l32.pth`（底模 `s2Gv4.pth` ＋ LoRA rank 32 自動合併） |
| 基礎模型 | GPT-SoVITS，分支 `main`，commit `48b1a0169a28582a8984402f82cf438d3bfa6aca` |
| 格式 | 48 kHz／mono／16-bit PCM |
| 參考音訊 | `data/ref/ref.wav`（＝ `wav/03536.wav`），prompt text 用 03536 原文 |
| 推論參數 | `top_k=15`、`temperature=1`、`sample_steps=32`、`cut1`、`seed=1234` |
| 總長度 | (a) 48.4 秒／(b) 38.0 秒，合計約 1.4 分鐘 |
